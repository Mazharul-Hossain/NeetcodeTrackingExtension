# P2 review fixes

Date: November 24, 2026.

Status: All five reported issues are fixed and regression-tested. Independent batch reviews found no blocking issues. The changes have not been exercised against live NeetCode submissions or real GitHub repositories in this follow-up.

## Fixes

| Issue | Current behavior | Regression evidence |
| --- | --- | --- |
| Stale Options fields could adopt another tab's newer version during Unlock or Lock. | Dirty fields retain their save version and require an explicit refresh. Pristine fields refresh before adopting the newer version; vault state still updates. | Unlock and Lock races against a focus refresh; dirty forms cannot overwrite the newer repository, pristine forms retain it on the next Save. |
| Sync completion consumed the latest execution for the tab. | The sync request ID owns a frozen capture from request start. Failed/error requests discard only that association. Older completions do not supersede newer successful syncs. Navigation and settings changes discard outstanding captures. | An intervening run, overlapping out-of-order syncs, failed older syncs, request errors, and Lock cleanup. |
| Captured code could be saved with a later language selector value. | Automatic messages carry the captured execution request's language. Manual code and language are read together from the Monaco model. Missing automatic language fails closed with a toolbar-retry instruction. | Changing Python to JavaScript after capture preserves `.py` in both paths; missing language never falls back to the current selector. |
| Deleting current Markdown could send saves back to a legacy folder. | The current directory wins whenever it exists at the immutable parent snapshot, even without `problem.md`. Legacy notes and solutions remain untouched. | Current folders containing only a solution or an unrelated README receive the new solution and regenerated Markdown. |
| Diagrams were omitted from problem Markdown. | HTTP(S) image references and escaped alternative text are preserved; relative sources resolve against the page. Executable/inline URLs are excluded, retaining alternative text. | Absolute/relative diagrams, escaped alt text, query backslashes, rejected protocols, and full extraction-to-upload Markdown. |

Each reported failure was reproduced in a failing test before its implementation fix. Tests use only synthetic code, credentials, request IDs, and repository contents.
